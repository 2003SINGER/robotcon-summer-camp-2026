# RobotCon 夏令营 2026

本仓库是夏令营机器人项目的协作入口：统一保存规则、机械设计、电控工程与现场状态，方便全组查看同一份资料，并保留每次改动的记录。

## 先看这里

1. [当前状态.md](当前状态.md)：唯一的现场状态记录。要改设计、加工或接线前，先确认这里的已验证事实、当前问题和下一次测试。
2. [参考规则](参考规则/)：2026 武林探秘及 2027 规则参考；以已确认的夏令营规则为准。
3. [协作指南.md](协作指南.md)：第一次使用 GitHub Desktop 的安装、同步和提交方法。

## 协作约定

- 每次开始前先在 GitHub Desktop 点击 **Fetch origin**；有更新就 **Pull origin**。
- 一次提交只做一件清楚的事，例如“更新底盘左侧板孔位”或“补充 M2006 CAN 参数”。提交信息写清改了什么、是否已上机验证。
- SolidWorks 的 `.SLDPRT`、`.SLDASM` 和场地模型不能自动合并。改动前先在群里说明自己正改的文件；不要两个人同时覆盖同一装配体。
- 遇到冲突或打不开的 CAD 文件，不要强行覆盖。先保留本地副本，再联系原修改者一起处理。
- 不上传编译输出、临时文件、软件安装包或带 `——` 前缀的本地参考资料。

详细操作见 [协作指南.md](协作指南.md)。
