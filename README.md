# RobotCon 夏令营 2026

2026 年 RobotCon 夏令营组队机器人项目的公开工程记录。仓库保留了从比赛规则、机械设计、电控工程到现场调试的协作材料；它展示的是一个真实机器人项目在有限硬件、时间和联调条件下如何推进，而不是已经完成、可直接复用的整机产品。

## 项目与结果

团队参加了 2026 年夏令营比赛，最终完成比赛；赛程记录为负—胜—胜—胜—负。比赛版采用了在现场可运行的最小流程：机构流程已完成可用调试，但底盘和机构控制板独立运行，底盘直行仍借助场地边缘作物理限位，部分机构动作依赖固定延时。因此，仓库中的 CAD、电控和现场记录应按其验证范围阅读，不能被外推为完整闭环控制或生产级方案。

## Lessons learned

- 并行开发的机器人项目应为底盘、机构和视觉准备独立的早期联调条件，避免所有模块在赛前才第一次集成。
- 在硬件尚未齐备时，先冻结通信接口和最小可运行流程，并为关键动作准备可验证的降级方案。
- 现场控制应优先提供确定、低延迟的动作闭环；依赖人工连续输入的临时控制容易产生响应延迟和过冲。
- 机械、电控和视觉的成熟度应分别标注，并以实测结果而不是目录结构或设计意图判断是否可复用。
