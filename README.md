## 当前整机方案（设计基线，待实测锁定）

> 本节记录当前采用的方案，替代此前已经废弃的传送带、低底盘和斜铝管主承力方案。几何尺寸、PID 参数和机构行程均不是“已验证结论”，以实物测试为准。

- **底盘**：四麦轮、`4 × M3508-P19` 驱动；重画为横向 H 型/工字型正交铝管骨架。左右连续主梁承载轮组、机构和板件，主承力铝管只走 90°；入口喇叭口由内侧斜玻纤板或低摩擦导向板实现。轮组需预留独立轴承支撑，避免麦轮继续悬臂加载在电机输出端。
- **KFS 仓**：前部 U 型开口容纳 KFS；左右两个水平伸缩托片用两只同步双作用气缸承托，托片本身要有导向，重量不得主要压在气缸杆上。主底盘和托片的首版目标是约 100 mm 离地，最终高度仍须与坡道、麦轮半径、轮距和斜轨几何一起确认。
- **前部取料**：取消传送带，采用一根倾斜直线轴上的单自由度真空吸盘。伸出时同时向前、向下吸取 KFS；回收时向后、向上带入仓内并在托片上方破真空。它应覆盖 200 mm / 400 mm 两档梅林，第二块进入时靠斜向上升越过第一块，不增设前部 Z 轴。
- **后部高位机构**：丝杆 + 双直线导轨 Z 轴，末端配置第二套真空吸盘及独立轴承支撑的水平 180° 翻转轴；翻转方向暂定 `GM6020 + 同步带减速`，用于顶部倒置 KFS 翻正与高位操作。
- **真空与气路**：一台电动真空泵供两套吸盘，两路各配一只 3/2 真空阀以独立吸附、破真空；两个托片气缸由单电控弹簧复位 5/2 阀同步控制。两只吸盘各预留真空检测输入。
- **当前未锁定参数**：H 型底盘长宽、离地高度、前后轮距、麦轮尺寸、斜轨角度/行程、托片高度、吸盘结构、Z 轴高度和丝杆导程。

### Xuke 电控项目的范围

`电控/xuke/M2006_Formal/` 目前只负责**中间伸缩吸盘的两段 M2006 电机**，并非整机底盘或气路控制程序。它通过 FDCAN 接收电机 `0x201`、`0x202` 反馈，向 `0x200` 下发两路电流命令，使用位置—速度串级 PID。当前源码的目标位置是固定测试值，尚未实现回零、行程限位、吸盘/真空联锁、故障停机或整机动作状态机；装车前必须补齐这些边界并实测。

## 协作约定

- 每次开始前先在 GitHub Desktop 点击 **Fetch origin**；有更新就 **Pull origin**。
- 一次提交只做一件清楚的事，例如“更新底盘左侧板孔位”或“补充 M2006 CAN 参数”。提交信息写清改了什么、是否已上机验证。
- SolidWorks 的 `.SLDPRT`、`.SLDASM` 和场地模型不能自动合并。改动前先在群里说明自己正改的文件；不要两个人同时覆盖同一装配体。
- 遇到冲突或打不开的 CAD 文件，不要强行覆盖。先保留本地副本，再联系原修改者一起处理。
- 不上传编译输出、临时文件、软件安装包或带 `——` 前缀的本地参考资料。

详细操作见 [协作指南.md](协作指南.md)。
