# 流程结构简单示意
第一阶段方案：yolo的KFS识别 + 单目相机视觉伺服 + 巡线（视觉中期检测要求为识别+ 巡线）
## 一、KFS识别与视觉伺服尝试

**文件**：`cpp_yolo_deploy`

### 1. Python端（`realtime.py`）

- **初始化**：加载YOLOv8模型、打开摄像头。
- **主循环**：
  1. 读取一帧图像。
  2. 用YOLOv8进行推理（`imgsz=640`），获得所有检测框。
  3. 收集所有KFS框（类别、坐标、面积、中心X）。
  4. 按中心排序，并标记干扰项（非本队）。
  5. 筛选本队目标（`ourColor`），选择面积最大的（距离最近）。
  6. 对选中的ROI进行边缘检测（Canny）计算KFS朝向角。
  7. 画框：本队绿框，干扰红框，并标注序号和标签。
  8. 通过`print`将数据（`x1 y1 x2 y2 cls angle interference_pos`）输出到`stdout`。
  9. 使用`cv2.imshow`实时显示画面。

### 2. C++端（`main.cpp`）

- **初始化**：读取标定文件 `calibration_data.yml`，获取相机内参（`fx, fy, cx, cy`）和畸变系数。
- **主循环**：
  1. 从`stdin`读取一行数据（`getline`），解析为 `x1 y1 x2 y2 cls angle interference_str`。
  2. 打印干扰位置到`cerr`（调试用）。
  3. 若`cls`匹配本队，进行以下计算：
     - **测距**：`Z = (REAL_KFS_HEIGHT * fx) / pixel_h`（单位：米）。
     - 中心点去畸变。
     - 计算世界坐标：
       - `X = ((p.x - cx) / fx) * Z`
       - `Y = ((p.y - cy) / fy) * Z`
       - `KFS_HEIGHT = CAMERA_HEIGHT - Y`
     - **方位角**：`azimuth_deg = atan2(X, Z) * 180/π`。
     - 判断是否到达抓取范围（`Z` 在 0.2~0.3m 且居中）。
  4. 输出结果到`cout`（终端），同时构造串口数据帧发送给下位机。

### 3. 串口通信（集成在C++中）

- 使用UART，波特率115200，数据位8，停止位1，无校验。（使用夏令营通讯教材的协议）
- **帧格式**：`？！S X低字节，X高字节，Z低字节，Z高字节，干扰位置，！`
- 下位机解析该字符串提取各字段。

## 二、摄像头巡线 (Line Tracking) 

基于 OpenCV 和纯 C++ 实现的赛道巡线算法，可通过 USB 摄像头实时提取赛道中心线，输出横向偏差，用于智能车或机器人循迹控制。

### 功能特点

- 实时读取 USB 摄像头（默认 `/dev/video0`）
- 图像预处理：高斯模糊 + CLAHE 自适应对比度增强（抗光照干扰）
- 动态行阈值二值化，适应不同远近光照变化
- 逐行扫描提取赛道左右边界和中心线
- 输出：横向偏差（`error`，单位：像素）和丢失标志（`lost`）
- 可视化窗口实时显示边界、中心线和偏差值
